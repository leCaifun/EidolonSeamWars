## 1. Принципы этапности

**Часть II. Дорожная карта.**

- Работа идёт строго по этапам; фичи вне текущего этапа не реализуются (ADR-021).
- Каждый этап завершается компиляцией, зелёными тестами и обновлённой документацией.
- Критерии приёмки M0 — все пункты [docs/GDD.md](GDD.md) §19.
- Балансные и дизайнерские изменения фиксируются в [docs/DECISIONS.md](DECISIONS.md)
  и [docs/BALANCE.md](BALANCE.md), а не «молча» в коде.
- История работ без Git ведётся в [docs/WORKLOG.md](WORKLOG.md) (ADR-019).

## 2. M0 — база за 24 часа

| Часы | Задача | Результат |
|---|---|---|
| 0–2 | Репозиторий, документация, solution, логгер, контент-схемы | Каркас компилируется |
| 2–5 | Core-домен: Hex, UnitDef, Stack, Army, Hero, Settlement, 7 ресурсов, DailyTick | Тесты домена зелёные |
| 5–8 | Гекс-карта 48×48, A*, туман, партии с героями и без, движение | Герой ходит, отряд ходит |
| 8–13 | Бой 13×9, очередь A/B, атака/способность/ожидание/защита, урон/крит/5 резистов, автоконтратака, мораль | Бой играбелен |
| 13–16 | Герой off-field: панель, заклинание, командная способность, левелап до 10, уникальные классы | Герой влияет на бой |
| 16–18 | Карточки юнитов, экран армии, экран поселения, осада MVP, захват с авто-удалением зданий | Полный цикл карта→бой→осада |
| 18–20 | Главное меню, настройки, сейв/лоад безлимит, тестовая битва с симуляцией | Меню→игра→сейв→лоад |
| 20–22 | Контент 3 фракций, ИИ базовый, эхо-схрон, шахты, жилища | Партия против 1 ИИ |
| 22–24 | Тесты, SimRunner smoke, логи, патчноут, сборка | MVP принят по §19 |

## 4. M1 — экономика и найм

Найм в поселениях и жилищах, дневной прирост, здания, улучшение поселений по
фракциям, отделения без героев, эхо-схроны полностью, караван, рынок,
7 ресурсов с реальными тратами.

## 5. M2 — RPG и контент

Навыки и подклассы героев, артефакты всех слотов, промоушены юнитов, 3 полных
ростера, квесты, репутация, боезапас стрелков с логистикой, обозы,
сера/древесина для боезапаса.

## 6. M3 — война за поселения

Технологии, полноценная осада со стенами/машинами, апгрейд поселений, найм героев,
строительство/разрушение вручную, кампания, сложные правила захвата
(оставить/конвертировать).

## 7. M4 — моды и сообщество

Скрипт-моды C# через Roslyn, песочница permissions, редактор карт/сценариев,
хот-сит, локализации, баланс-харнесс.

## 8. M5 — сеть и DLC

Мультиплеер, сеты снаряжения, первое DLC как мод, Workshop, продвинутый ИИ,
реплей боёв.
