## 1. Принципы

- Каждый экран отвечает на один вопрос игрока; лишние панели скрываются.
- Действие всегда показывает цену и последствия до подтверждения.
- Никакого автобоя в игровых режимах; симуляция — только тестовый режим.
- Ошибки и недоступные действия объясняются текстом, а не только цветом.
- Все строки — ключи локализации, никакого текста в коде.
- UI не пересчитывает правила: отображает состояние и отправляет команды.

## 2. Честные заглушки

Нереализованные режимы:

- пункт disabled либо экран `ComingSoon`;
- tooltip «В разработке» с указанием этапа;
- никогда не выглядят как рабочие и не имитируют загрузку.

Заглушки MVP: кампания, сценарий, хот-сит, мультиплеер, редактор, часть справки.

## 3. Карта экранов

```
MainMenu
├── NewGameScreen ──► RandomMapGameScreen ──► BattleScene / SettlementScreen
│                 └► TestBattleScreen ──► BattleScene
├── LoadScreen ──► RandomMapGameScreen
├── SaveScreen (из игры)
├── SettingsScreen
├── ModsScreen
├── HelpScreen
└── ComingSoon (заглушки)
```

Переходы не теряют состояние без подтверждения. Выход из боя на карту — через итог боя.

## 5. Новая игра

- Кнопка «Одиночная случайная карта»: создаёт карту 48×48, игрока, 1 ИИ,
  нейтральное поселение третьей фракции (GDD §19).
- Выбор фракции игрока; фракции ИИ и нейтралов — по правилам сценария.
- Поле сида (опционально, для воспроизводимости).
- Кнопка «Тестовая битва» ведёт в §11.
- Кампания и сценарий — disabled.

## 6. Экран карты

Обязательные элементы:

- гекс-карта 48×48 с туманом войны;
- панель ресурсов: 7 ресурсов и день;
- кнопки «Завершить день», «Армия», «Поселения», «Сохранить»;
- выделенная партия и её очки движения;
- подсказка объекта под курсором;
- журнал событий дня (сворачиваемый).

Правила взаимодействия:

- клик по достижимому гексу двигает партию, клик по недостижимому показывает причину;
- клик по объекту открывает карточку взаимодействия;
- туман: разведка открывается навсегда, стоки и охрана не запоминаются (GDD §4);
- «Завершить день» запускает дневной тик с индикатором выполнения.

## 7. Экран боя

Обязательные элементы:

- поле 13×9 с гексами, препятствиями и опасными тайлами;
- подсветка доступного движения и атаки;
- очередь хода по группам A/B с индикатором ожидания;
- панель действий: атака, способность, ожидание, защита;
- карточка выбранного юнита;
- командная панель героя: портрет, мана, заклинание, командная способность;
- лог боя;
- итог боя: потери, опыт, ветеранство, возврат на карту.

Запрещено: кнопка контратаки, кнопка автобоя, токен героя на поле,
отображение боезапаса.

## 8. Карточка юнита

Форма: прямоугольник со скруглёнными углами; рамка и фон — цвета фракции.
Макет по GDD §8:

| Зона | Содержимое |
|---|---|
| Верх | фракция · класс · название; тир; описательный ранг ветеранства |
| Слева | изображение; бейдж количества или значок героя; иконка типа передвижения |
| Справа | лидерство, атака, защита + ненулевые резисты, инициатива, скорость, урон, крит. шанс, крит. урон, HP, текущее HP верхнего юнита |
| Ниже | пассивные/активные способности с иконками, кулдаунами, зарядами |
| Внизу | текущие бафы/дебафы с длительностью |

Правила:

- резисты показываются только ненулевые;
- ранг ветеранства — словом, не числом;
- боезапас не отображается;
- значения не пересчитываются UI: берутся из домена;
- карточка работает и для героя (без HP на поле).

## 9. Экран героя

- Портрет, имя, фракция, уникальный класс.
- Уровень и опыт; soft cap 10 отображается как ориентир сценария.
- Характеристики: атака, защита, чародейство, знание, лидерство, логистика.
- Мана: `10 + Знание × 5`.
- Слоты артефактов по GDD §9.4: голова, шея, руки (2), плечи, торс, спина, пояс,
  ноги, стопы, кольца (2); правила двуручного и парных слотов.
- Навыки: заглушка «Появится в M2» (честная, неактивная).

## 10. Экран поселения

- Владелец, шаблон, уровень, гарнизон.
- Построенные здания и слоты.
- Доступные юниты и найм с проверкой лидерства.
- Очередь строительства и стоимость.
- Кнопка атаки на чужое поселение: предупреждение о сносе зданий и сбросе уровня
  (ADR-013), затем `SiegeMvp`.
- Для поселения без владельца — флаг захвата, если охрана побеждена.

## 11. Тестовая битва

- Выбор фракций и состава армий.
- «Начать битву» — ручной бой.
- «Симулировать бой» — мгновенный headless-прогон с результатом и логом.
- Повтор и смена сида; повтор той же битвы.
- Симуляция помечена как тестовый режим и недоступна в обычной игре.

## 12. Настройки

| Настройка | Значения | Применение |
|---|---|---|
| Разрешение | список поддерживаемых | без перезапуска, если возможно |
| Режим окна | оконный / полноэкранный | без перезапуска |
| Музыка | вкл/выкл + громкость | сразу |
| Звуки | вкл/выкл + громкость | сразу |
| Язык | RU / EN | живое переключение |

Изменения логируются (`Settings`). Недоступные значения disabled с пояснением.

## 13. Сохранение и загрузка

- Безлимитные слоты; имя, дата, день, фракция, уровень героя.
- Кнопки: сохранить, загрузить, перезаписать, удалить.
- Перезапись и удаление — с подтверждением.
- Автосохранение отображается отдельной записью.
- Ошибка записи показывается текстом и логируется, слот не повреждается.

## 14. Моды и справка

- Моды: список data-паков, включение/выключение, порядок загрузки, лог конфликтов.
- Справка: управление, правила боя, расшифровка карточки, горячие клавиши.
- Справка не дублирует GDD целиком: краткие правила для игрока.

## 15. Визуальные токены

Базовые цвета фракций (GDD §2.2):

| Фракция | Основные | Акцент |
|---|---|---|
| Латунный Предел | сталь `#2C3E50`, латунь `#B8863B` | алый `#C0392B` |
| Пепельный Ковен | пепел `#3A3A3A`, кость `#D8D2C4` | фиолетовый `#8E7CC3` |
| Корневые Кланы | изумруд `#2E8B57`, кора `#8B5A2B` | охра `#D4A017` |

Фон интерфейса — тёмный нейтральный; контраст текста ≥ 4.5:1.
Токены хранятся в `game/assets/themes`, не в коде экранов.

## 16. Локализация и доступность

- Все строки — ключи `ui.*`, `core.*`; RU/EN переключаются на лету.
- Числа и даты форматируются по текущей локали; боевые числа — целые.
- Иконки дублируются текстом или tooltip.
- Управление только мышью и клавиатурой; горячие клавиши документируются в справке.
- Разрешение по умолчанию — 1920×1080, UI масштабируется; минимальное — 1280×720.

## 17. Статус этапа 01

Ни один экран не реализован. `game/scenes/*` и `game/scripts/*` содержат только
структуру каталогов; `BootController` пишет версию в лог. Это соответствует
этапу M0 и не считается заглушкой геймплея.

### Макет

```text
┌─────────────────────────────────────────────────────────┐
│ [G 250] [W 5] [O 5] [C 2] [S 1] [M 1] [E 3]   День 15   │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                     [Гекс-карта 48×48]                  │
│                                                         │
│                                                         │
│                                                         │
├─────────────────────────────────────────────────────────┤
│  [Завершить день]   [Армия]   [Поселения]  [Сохранить]  │
└─────────────────────────────────────────────────────────┘

Компоненты
Панель ресурсов (вверху):
7 иконок с текущим количеством.
Счётчик дня справа.
Кнопка перехода к следующему дню.
Гекс-карта (центр):
48×48 гексов, прокрутка/зум.
Туман войны: видимое/исследованное/скрытое.
Объекты карты (шахты, поселения и т.д.).
Партии с героями и отряды без героев.
Подсветка достижимых гексов при клике на партию.
Панель управления (внизу):
«Завершить день» — запускает MapCommand EndDay.
«Армия» — открывает экран состава армии.
«Поселения» — список своих поселений.
«Сохранить» — меню сохранений.
Взаимодействие
Клик на пустой гекс → выделение (если партия).
Клик на достижимый гекс → движение (MapCommand Move).
Клик на объект → открыть диалог объекта / начать бой.
Клик на вражескую партию → начать бой.
Клик на героя → экран героя.
Правая кнопка → отмена / контекстное меню.
Колёсико / щипок → зум.
Средняя кнопка → pan.
Состояния
Без выделения: карта в покое.
Выделена партия: подсветка достижимых гексов, отображение MP.
Открыт диалог объекта: затемнение фона, модалка.
Бой: переход на экран боя (этап 05).
