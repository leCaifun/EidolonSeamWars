## 1. Перед релизом

- [ ] Все задачи этапа закрыты, WORKLOG заполнен.
- [ ] Известные проблемы внесены в `docs/KNOWN_ISSUES.md`.
- [ ] Нет незакоммиченных заглушек в реализуемой части (TODO запрещены).
- [ ] Незавершённые режимы UI — честные disabled + «В разработке».
- [ ] Критерии GDD §19 проверены по пунктам.

## 2. Сборка и тесты

- [ ] `dotnet build EidolonSeamWars.sln -c Release`.
- [ ] `dotnet test EidolonSeamWars.sln -c Release` — 0 провалов.
- [ ] `tools/scripts/validate` — валидатор пройден (этап 03+).
- [ ] Сборка Godot-проекта без ошибок C#.
- [ ] Нет предупреждений, скрывающих реальные проблемы.

## 3. Контент и валидация

- [ ] Все JSON валидны и имеют `schemaVersion`.
- [ ] Нет дубликатов ID и битых ссылок.
- [ ] Локализация RU/EN паритетна, нет пустых значений.
- [ ] Все 7 ресурсов отображаются.
- [ ] Новый контент добавлен только JSON + локализацией.
- [ ] Моды загружаются и конфликты логируются.

## 4. Документация и версии

- [ ] `docs/CHANGELOG.md` обновлён под релиз.
- [ ] `docs/patchnotes/vX.Y.Z.md` создан.
- [ ] Версия совпадает в `Directory.Build.props`, `project.godot`, CHANGELOG.
- [ ] `docs/ROADMAP.md` отражает завершённый этап.
- [ ] `docs/BALANCE.md` содержит все балансные правки (старое/новое/причина).
- [ ] README и RUNBOOK актуальны.

## 5. Сохранения и миграции

- [ ] Save→load round-trip на текущей версии.
- [ ] Миграции со всех поддерживаемых версий проходят.
- [ ] Автосохранение не блокирует игру.
- [ ] Повреждённый сейв не роняет игру.
- [ ] Безлимитные слоты и метаданные работают.

## 6. Логи и стабильность

- [ ] Логи пишутся в `logs/`, ротация 5×10 МБ.
- [ ] Обязательные точки логирования присутствуют.
- [ ] Crash-отчёт создаётся и содержит последние 200 строк.
- [ ] Нет утечек и роста памяти в длинной сессии (30+ минут).
- [ ] Alt+Tab, смена разрешения и языка не ломают UI.

## 7. IP и ассеты

- [ ] Все ассеты в `docs/ASSET_LICENSES.md`.
- [ ] Нет чужих имён, символов, текстов и музыки.
- [ ] Атрибуция CC-BY добавлена.
- [ ] Шрифты лицензированы для распространения.
- [ ] AI-промты и результаты не нарушают IP-политику.

## 8. Ручной smoke

- [ ] Главное меню навигируемо, заглушки честные.
- [ ] Новая игра создаёт карту 48×48 с игроком, ИИ и нейтральным поселением.
- [ ] Герой и отряд без героя двигаются, туман работает.
- [ ] День тикает: доход, прирост, эффекты, ИИ, автосейв.
- [ ] Армия 5 слотов, лидерство жёсткое.
- [ ] Карточка юнита показывает все поля, без боезапаса.
- [ ] Бой 13×9: атака, способность, ожидание, защита, криты, резисты, контратака.
- [ ] Мораль описательная, капы, иммунитет нежити.
- [ ] Герой вне поля, кастует, командная способность 1/бой.
- [ ] Осада, захват, автоудаление зданий, сброс уровня.
- [ ] Побег и выкуп по формулам.
- [ ] Тестовая битва симулируется мгновенно.
- [ ] Настройки и RU/EN переключаются.
- [ ] Сейв/лоад и удаление слота.
