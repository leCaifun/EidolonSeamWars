## 1. Как пользоваться

Термины даны на русском, английском и в виде идентификатора кода.
В коде используются английские идентификаторы; в документации и UI — русские термины.
Если термин встречается в GDD и здесь по-разному — приоритет у GDD.

## 3. Карта и армии

| RU | EN | Код | Значение |

| Лидерство | Leadership | `Leadership` | Жёсткая ёмкость армии |
| Туман войны | Fog of war | `FogOfWar` | Скрытые области и объекты карты |
| Эхо-схрон | Echo cache | `EchoCache` | Объект с тремя контрактами: вскрыть, договориться, оставить печать |

## 7. Технические термины

| RU | EN | Код | Значение |
|---|---|---|---|
| Ядро | Core | `Game.Core` | Чистая C#-библиотека правил |
| Домен | Domain | `Game.Core.Domain` | Сущности и правила игры |
| Команда | Command | `BattleCommand`, `MapCommand` | Единственный способ менять состояние |
| Событие | Event | `IDomainEvent` | Уведомление о факте |
| Сид | Seed | `masterSeed` | Начальное значение RNG |
| Стрим | Stream | `RngStreamKind` | Независимая последовательность RNG |
| Реплей | Replay | `commandLog` | Воспроизведение по журналу команд |
| Сейв | Save | `SaveGame` | Файл состояния партии |
| Миграция | Migration | `ISaveMigration` | Перевод старого формата в новый |
| Контент-пак | Content pack | `contentPack` | Набор JSON-данных |
| Мод | Mod | `manifest.json` | Data-пак в `mods/` |
| ADR | Architecture Decision Record | — | Запись решения в DECISIONS.md |
| DoD | Definition of Done | — | Критерии готовности задачи |
| M0–M5 | Milestones | — | Этапы дорожной карты |
| Заглушка | Stub | `ComingSoon` | Честно неактивный элемент «В разработке» |
| RNG | Random number generator | `SeededRandom` | Детерминированный генератор |
