2. Сеттинг
### 2.1. Мир
Эйдолон — мир, сшитый из осколков погибших реальностей древней цивилизацией Ткачей. Ткачи исчезли, швы расползаются. Из-за швов приходит Голод — не армия, а состояние мира: земля забывает, какой должна быть, живые существа становятся чужими сами себе.
За стабильность отвечают Якоря — устройства Ткачей в основаниях городов. Фракции воюют за них: Якорь даёт власть над реальностью вокруг — урожай, законы физики, право мёртвых оставаться мёртвыми.
Тон: героический гримдарк с иронией. Победить можно, но каждая победа чего-то стоит. Юмор — в предметах, побочных персонажах, бюрократии апокалипсиса, не в ключевых трагедиях.

3. Столпы дизайна и core loop
Столпы:
Армия — это билд. Состав, ранги, промоушены, артефакты, герой — всё влияет на стиль.
Карта — экономика решений. Каждый день движения — выбор: шахта, жилище, эхо-схрон, патруль, город.
Бой — головоломка с ценой ошибки. Потери постоянны. Ручное управление всегда выгоднее симуляции.
Всё — контент. Юнит, здание, артефакт, заклинание, объект карты, ИИ-профиль — данные + опциональный скрипт.
Моды — граждане первого класса. DLC неотличимо от мода.
Core loop:
Минута: ход в бою / шаг по карте / решение о найме.
Час: зачистка региона → найм в логове → ранг стака → бой с хранителем → артефакт.
Сессия 2–4 ч: захват поселения → дневная экономика → квест → битва за Якорь.
4. Глобальная карта
Гексагональная сетка (axial). Размер случайной карты MVP: 48×48.
Базовая единица симуляции и экономики — 1 день. Неделя только как UI-группировка, не механика.
День/ночь отсутствует полностью.
Туман войны: радиус обзора партии, разведка открывается навсегда, объекты помнятся, стоки/охрана — нет.
### 4.1. Партии на карте
Армии с героем: бонусы героя, подбор артефактов, квесты, магические объекты, лидерство по формуле KB.
Отряды без героев: патрули, гарнизоны, караваны, отделённые игроком отряды. Двигаются, воюют, захватывают экономические объекты. Без бонусов героя, без квестов, без артефактов. Фиксированная ёмкость лидерства.
Игрок отделяет/сливает отряды через экран армии. У отряда без героя собственный запас очков движения.
### 4.2. Объекты карты
Поселения, шахты (7 ресурсов), внешние жилища (селения, логова, гнёзда, склепы, алтари, лагеря наёмников), ресурсные кучки, эхо-схроны, артефакты на земле, нейтральные патрули, руины Ткачей (будущее: технологии), святилища/обелиски/порталы (будущее).

6. Армии, лидерство, слоты
### 6.1. Лидерство — жёсткий лимит, без перегруза
У каждого юнита leadershipCost.
Армия с героем: ёмкость = hero.Leadership (формула King’s Bounty: стат лидерства напрямую = ёмкость).
Отряд без героя: ёмкость = 50 (фиксированное сбалансированное значение MVP).
Перегруз невозможен. Найм/передача/слияние блокируются, если сумма leadershipCost × count превысит ёмкость. UI показывает занято/ёмкость и остаток.
Артефакты и навыки могут повышать Leadership.
### 6.2. Слоты армии
Базово 5 слотов, максимум 7 в будущем.
Почему 5: как KB — каждый слот meaningful choice, меньше микро, проще баланс и ИИ.
Расширение будущее: навык «Штабная выучка» (+1), артефакт-знамя (+1), здание «Штаб снабжения» (+1 для гарнизонов).
Герои не занимают слоты. В армии только один главнокомандующий-герой. Армия из нескольких героев — будущее, не MVP.
### 6.3. Герой не участвует в бою напрямую
Герой — главнокомандующий вне поля. Нет токена героя на гексах, нет HP на поле, его нельзя атаковать.
Герой даёт армии пассивные бонусы: атака, защита, лидерство, классовые механики.
Герой кастует заклинания через командную панель (1/раунд, мана).
Командная способность класса: 1/бой.
Поражение армии = побег или плен героя по правилам §7.8.
7. Боевая система
### 7.1. Поле
Гексы 13×9. Препятствия, разрушаемое укрытие, опасные тайлы, трупы как ресурс для некромантии. Осада MVP: обычное поле, атакующий против гарнизона, без стен/ворот/башен/машин.
### 7.2. Стак-модель
Отряд = тип × количество. Количество — пул HP. Урон снимается с верхнего юнита, остаток переносится. Герой на поле не стоит.
### 7.3. Порядок хода и действия
Раунд = две группы:
Группа A: не ожидавшие в прошлом раунде, по убыванию инициативы.
Группа B: ожидавшие в прошлом раунде, по убыванию инициативы.
Тай-брейк: чередование сторон, затем индекс слота.
Действия:
Атака — ближняя или дальняя.
Активная способность — кулдаун/заряды.
Ожидание — перенос в конец текущего раунда, флаг waitedLastRound=true. В следующем раунде — группа B. Повторное ожидание в том же раунде запрещено.
Защита — +25% к защите до следующего хода юнита. Резисты не даёт. Инициативу не снижает.
Контратака — не действие. Это автоматический ответ на ближнюю атаку: 1 за раунд, если защитник выжил и атакующий в зоне досягаемости. Абилки могут давать «без контратаки», «бесконечная контратака». Кнопки контратаки нет.
### 7.4. Урон, крит, резисты
Целочисленная формула per-mille:
base = count × Random(minDamage, maxDamage)
atkDefMod = 1000 + 50 × (Attack − Defense)
clamp(atkDefMod, 300, 4000)   // −70% … +300%
raw = base × atkDefMod / 1000
далее: резисты по типу урона, дистанция, укрытие, бафы/дебафы
крит: если roll < critChance → raw × critDamageMod / 100
Крит. шанс: базово 5–15%, кап 75%.
Крит. урон: базово 150%, кап 300%.
Резисты (временно): физический, магический, ядовитый, огненный, огнестрельный. Показываются в карточке только ненулевые.
Типы урона: ближний бой → физический; аркебузы/порох → огнестрельный; заклинания → магический; огненные эффекты → огненный; яд → ядовитый.
### 7.5. Мораль — экспоненциальная, описательная

Нежить и конструкты: иммунитет к морали, всегда 0.
Clamp −4…+4.
### 7.6. Герой в бою — косвенно
Командная панель: портрет, мана, заклинание, командная способность.
Заклинание: 1/раунд, мана = 10 + Знание × 5, стоимость в мане.
Командная способность: 1/бой.
Пассивно: атака/защита героя добавляются армии, классовые механики работают.
Герой не атакуем, не стоит на поле, не имеет HP на поле.
### 7.7. Отступление и выкуп
Побег (отступление):
Герой пытается бежать, бросив армию.
Шанс: clamp(65 + heroLogistics×3 − enemyLogistics×2, 20, 90)%.
Успех: к началу следующего дня герой появляется в ближайшем своём поселении, без армии, теряет 1–3 случайных артефакта, передающихся противнику, от которого бежал. Если противник без героя — артефакты теряются.
Провал: герой пленён на 5 дней, армия потеряна, артефакты 1–3 переходят противнику.
Армия, брошенная при побеге, теряется полностью.
Отряд без героя не бежит: разгром, потеря 40% стаков, рассеивание к ближайшему своему поселению.
Побег защитника осады запрещён.
Выкуп (сдача):
Цена = Σ(unitPrice × count) + heroLevel × 1000 + 100 × artifactCount.
Коэффициенты в data, можно балансировать.
Оплата: герой и выжившая армия сохраняются, появляются в ближайшем своём поселении, 0 очков движения до конца дня, артефакты не теряются.
Не хватает золота — кнопка недоступна.
Выкуп защитника осады запрещён.
### 7.8. Автобой
В игре автобоя нет. Симуляция только в отдельном тестовом режиме для разработки и баланса. В обычной игре все бои вручную.
8. Карточка юнита
Форма: прямоугольная, скруглённые углы. Рамка и фон — цветов фракции юнита.
Верх: фракция · класс · название. Дополнительно: тир и ранг ветеранства (описательно, не цифрой).
Слева: изображение. Снизу по центру — бейдж количества юнитов или значок героя. Тип передвижения иконкой (пехота/летун/стрелок/осадный).
Справа, характеристики:
Лидерство на юнита.
Атака.
Защита + конкретные резисты (физический, магический, ядовитый, огненный, огнестрельный; только ненулевые).
Инициатива.
Скорость.
Диапазон урона.
Крит. шанс, %.
Модификатор крит. урона, %.
Здоровье юнита.
Текущее здоровье верхнего юнита (полоса + число).
Под характеристиками: пассивные/активные абилки с иконками, кулдаунами, зарядами.
Ещё ниже: текущие бафы/дебафы значками с длительностью.
Боезапас пока не отображается. Поле в data зарезервировано.
### 8.1. Ветеранство
Бесплатно, ранги 1–5, описательно.
Основано на количестве побеждённых отрядов (добитых enemy stacks, не юнитов).
Пороги: 0 / 2 / 5 / 10 / 18 побеждённых отрядов.
За каждый ранг выше 1: +2 атака, +2 защита, +1 п.п. крит. шанс, +1 п.п. крит. урон.
Ранг 5: +8 атака/защита, +4 крит. шанс/урон.
Названия: Новобранцы → Обстрелянные → Ветераны → Закалённые → Легенды.
Сохраняется за стаком, отображается на карточке.

### 9.5. Ранение, побег, плен
Побег успешен → герой в ближайшем поселении к началу следующего дня, без армии, минус 1–3 артефакта.
Побег провален → плен на 5 дней.
Армия разбита без побега → герой автоматически пытается бежать по тем же правилам.
Ранение в MVP не используется отдельно; побег/плен заменяют.
### 9.6. Кривая опыта
XP до следующего уровня:
XpToNext(level) = 50 × level × (level + 1)
| Уровень | XP до следующего |
|---:|---:|
| 1→2 | 100 |
| 2→3 | 300 |
| 3→4 | 600 |
| 4→5 | 1000 |
| 5→6 | 1500 |
| 6→7 | 2100 |
| 7→8 | 2800 |
| 8→9 | 3600 |
| 9→10 | 4500 |
Суммарно до 10 уровня: 16 500 XP.
Суммарный XP для перехода с уровня 1 на уровень (steps + 1): 50 × steps × (steps + 1) × (steps + 2) / 3.
Опыт не сбрасывается: накопленный XP сравнивается с порогами последовательно.
За уровень: +1 к случайной характеристике по весам класса и +1 очко навыка.
Очки навыков копятся, но не тратятся в MVP.
Уровень не ограничен; soft cap 10 задаётся сценарием (0 или меньше — без предела).
10. Прогрессия юнитов
Ветеранство: бесплатно, ранги 1–5 по побеждённым отрядам, бонусы §8.1.

11. ИИ
Стратегический: utility-AI, цели: развивать поселение, захватывать шахты, нанимать, защищать город, атаковать слабого героя, собирать эхо-схроны. Веса в data.
Тактический: influence map, оценка цели по ожидаемому урону минус контратака плюс шанс добить плюс ценность цели, кайт стрелками, фокус огня, способности и заклинания героя.
Симуляция: headless-прогон теми же правилами, для тестов и баланс-матриц. Не игровой автобой.

17. Боезапас стрелков — решение на будущее
Решение: да, боезапас будет в M2+, но не в MVP. Причина: без логистики боезапас — просто раздражитель; с логистикой — тактический слой.
Будущие механики:
maxAmmo, shotsLeft, выстрел тратит 1.
Нет боезапаса → стрелок дерётся в melee со штрафом −50% урона.
Обоз/телега с боеприпасами — отдельный отряд, восполняет соседним стрелкам.
Караван/поселение восполняет боезапас.
Сера + древесина → производство боезапаса.
Абилки: «Залп» (2 боезапаса, AoE), «Прицельный выстрел» (2, +крит), «Огневая поддержка» (аура).
Заклинание «Восполнить боезапас».
Артефакты: «Бесконечный колчан», «Пороховой пояс».
ИИ учитывает остаток боезапаса при выборе цели.
В MVP: стрелки без боезапаса, поле в data зарезервировано, UI не показывает.

19. Критерии приёмки MVP
Главное меню полностью навигируемо, заглушки честные.
Новая игра создаёт карту 48×48 с игроком, 1 ИИ и нейтральным поселением третьей фракции.
По карте ходят армии с героями и отряды без героев.
День тикает: доход, прирост, эффекты, ИИ, автосейв.
Армия из 5 отрядов + герой, лидерство жёсткое, перегруз невозможен.
Карточка юнита: фракционные рамка/фон, все поля, тир, описательный ранг, тип передвижения, резисты, без боезапаса.
Бой на гексах 13×9: атака, способность, ожидание по правилам, защита +25% def без резистов и без штрафа инициативы, криты, 5 резистов, автоматическая контратака 1/раунд.
Мораль экспоненциальная, описательная, оба эффекта, капы, иммунитет нежити/конструктов.
Герой не на поле, кастует через панель, командная способность 1/бой, качается до 10, +1 к случайной weighted хар-ке.
Простейшая осада: бой против гарнизона, захват поселения, здания авто-удаляются, уровень сбрасывается до 1, шаблон переключается.
Побег и выкуп работают по формулам.
Тестовая битва запускается и симулируется мгновенно с результатом.
Настройки применяются, RU/EN переключаются.
Безлимитные сейв-слоты с метаданными.
Логи пишутся, тесты ядра зелёные.
В Game.Core нет using Godot.
Добавление нового юнита требует только JSON + локализации.
Все 7 ресурсов отображаются и тикают.
