# Modding Policy

You may create and distribute mods for this game.

Allowed:
- free mods;
- original assets;
- custom JSON content packs;
- custom maps, units, factions, abilities, localization;
- using the modding API and SDK examples.

Not allowed without permission:
- redistributing official game assets or core content packs;
- using official trademarks as your own product identity;
- selling mods that contain official assets;
- circumventing licensing or DRM, if any.

Mods must include a manifest and may be loaded from the mods directory.
See docs/MODDING.md for technical details.

The official game and its assets remain proprietary.
