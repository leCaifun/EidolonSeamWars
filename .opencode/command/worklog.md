Добавь запись в `docs/WORKLOG.md` о работе: $ARGUMENTS

Формат записи (AGENTS.md, prompts/00_mvp.md):

```
## W-XXXX · YYYY-MM-DD · <этап ROADMAP / короткое имя>

**Цель:**
**Создано:**
**Изменено:**
**Удалено:**
**Тесты:** команды и результат
**Проверено руками:**
**Не проверено:**
**Риски и техдолг:**
**Commit-message для будущего Git:** <Conventional Commits>
```

Правила:

1. ID — следующий по порядку после последней записи.
2. Дата — текущая.
3. Перечисляй реальные файлы, не выдумывай проверки.
4. Если тесты не запускались — так и напиши.
5. Не выполняй git-команды.
