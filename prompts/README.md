## 1. Назначение

Каталог содержит пошаговые задания для AI-агентов. Промты детализируют этапы
[docs/ROADMAP.md](../docs/ROADMAP.md) и не расширяют границы MVP (ADR-021).
Промт — это задание, а не источник истины: при конфликте приоритет у
[docs/GDD.md](../docs/GDD.md) и [docs/DECISIONS.md](../docs/DECISIONS.md).

## 3. Общие правила для агента

1. Прочитать [AGENTS.md](../AGENTS.md) и релевантные секции [docs/GDD.md](../docs/GDD.md).
2. Прочитать [docs/DECISIONS.md](../docs/DECISIONS.md) и последние записи
   [docs/WORKLOG.md](../docs/WORKLOG.md).
3. Выдать план на 3–7 пунктов до кода.
4. Писать полными файлами, без `...` и без TODO в реализуемой части.
5. Git — только по правилам [AGENTS.md](../AGENTS.md) §5 (ADR-029): локальные коммиты разрешены, `git push` запрещён.
6. Не хардкодить контент: юниты, фракции, здания, заклинания — только JSON.
7. Держать `src/Game.Core` свободным от `using Godot` и плавающей точки.
8. Все изменения состояния — команды; случайность — только seeded-стримы.
9. После кода: `dotnet build`, `dotnet test`, валидатор контента, если он уже есть.
10. Обновить документы, [docs/WORKLOG.md](../docs/WORKLOG.md) и
    [docs/CHANGELOG.md](../docs/CHANGELOG.md).
11. В отчёте указать: сделано, как проверить, что не проверено, риски.
12. Если задача затрагивает больше 7 файлов — дробить на подзадачи.
