## 1. Цель

Сделать читаемый UI: карточку юнита строго по GDD §8, экран армии, экран
поселения и осаду MVP с захватом и автоудалением зданий.

## 3. Задачи

1. Реализовать `UnitCard` по GDD §8: рамка и фон цветов фракции, тир,
   описательный ранг, тип передвижения, все поля карточки, ненулевые резисты.
   Боезапас не показывать.
2. Реализовать экран армии: 5 слотов, занято/ёмкость лидерства, остаток,
   запрет перегруза с понятным сообщением.
3. Реализовать экран героя: портрет, имя, фракция, класс, уровень, опыт,
   характеристики, слоты артефактов; блок навыков — честная заглушка
   disabled + «Появится в M2».
4. Реализовать экран поселения: уровень, владелец, гарнизон, здания,
   кнопка атаки на чужое поселение.
5. Реализовать осаду MVP и экран результата: захват, автоудаление зданий,
   сброс уровня до 1, смена шаблона на фракцию захватчика.
6. Показывать предупреждение о сносе зданий до подтверждения атаки.
7. Обеспечить адаптацию карточки к RU/EN без обрезки текста и без хардкода строк.
8. Добавить логирование открытия экранов и ошибок UI (категория `UI`).

## 4. Правила UI

- Только ключи локализации; ни одной пользовательской строки в C#.
- `float` допустим только в presentation-слое.
- Заглушки только честные: disabled + «В разработке» / «Появится в M2».
- Карточка не показывает боезапас (ADR-015) и нулевые резисты.
- Перегруз армии невозможен: кнопки блокируются до применения команды.
- Цвета фракций берутся из данных, а не из магических констант.

## 5. Тесты

- Карточка отображает все обязательные поля GDD §8.
- Нулевые резисты скрыты, ненулевые показаны.
- Ранг ветеранства описательный, не числовой ярлык.
- Экран армии блокирует найм/передачу при превышении лидерства.
- Захват: здания удалены, уровень 1, шаблон захватчика.
- Осада: защитник не может бежать или выкупиться.
- Локализация: нет отсутствующих ключей на экранах.

## 7. Критерии приёмки

- Карточка юнита соответствует GDD §8 и показывает цвета фракции.
- Экран армии показывает занято/ёмкость и не допускает перегруз.
- Экран поселения и осада работают, захват автоудаляет здания.
- Предупреждение о сносе показывается до атаки.
- Все строки локализованы, отсутствующих ключей нет.
- Заглушки честные, без фальшивой функциональности.
- Build и тесты зелёные, документы обновлены.
