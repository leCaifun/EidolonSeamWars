## 1. Цель

Добавить базовый ИИ, наполнить карту объектами (эхо-схроны, шахты, жилища,
патрули) и реализовать headless SimRunner: smoke-прохождение и быструю симуляцию.

## 3. Задачи

1. Реализовать базовый ИИ по GDD §11: оценка армии, движение к целям, найм,
   захват объектов, атака слабых партий, отступление при явном проигрыше.
2. Все решения ИИ — детерминированные, через seeded-стримы; каждое решение
   логируется категорией `AI`.
3. Реализовать эхо-схрон: три варианта выбора награды, данные — JSON.
4. Реализовать шахты всех 7 ресурсов и внешние жилища с дневным приростом.
5. Реализовать нейтральные патрули как отряды без героя.
6. Реализовать SimRunner `smoke`: новая игра → движение → завершение дня →
   бой → осада → сейв → лоад, с кодом возврата 0/1.
7. Реализовать SimRunner `simulate --seed N --battles M`: результат, потери,
   число раундов; вывод стабилен при одинаковом сиде.
8. Подключить `validate` из этапа 03 к SimRunner, если ещё не подключён.
9. Убедиться, что ИИ не получает читерских ресурсов и не действует вне правил.

## 4. Правила

- ИИ не меняет состояние напрямую: только через `MapCommand`/`BattleCommand`.
- Никакого автобоя в игровых режимах; симуляция — только SimRunner/тест.
- Решения ИИ воспроизводимы при одинаковом сиде и состоянии.
- Объекты карты — данные, без хардкода имён и наград.
- Ошибки pathfinding и тупики ИИ логируются, а не проглатываются.

## 5. Тесты

- ИИ завершает ход и не зависает на карте без пути.
- Одинаковый сид → одинаковые решения и результат.
- Эхо-схрон: три варианта, выбор применяется корректно.
- Шахты и жилища дают прирост по дневному тику.
- Патруль без героя использует ёмкость 50.
- SimRunner `smoke` проходит полный цикл.
- SimRunner `simulate` детерминирован по сиду.

## 7. Критерии приёмки

- Партия против 1 ИИ проходима без зависаний.
- ИИ действует по правилам и детерминирован.
- Эхо-схроны, шахты, жилища и патрули работают из данных.
- `SimRunner smoke` проходит полный цикл.
- `SimRunner simulate` воспроизводим по сиду.
- Build и тесты зелёные, документы обновлены.
