КЛЮЧЕВЫЕ ПРАВИЛА (не нарушать):
- Гексы и на глобальной карте, и в бою. День/ночь нет.
- Экономика: базовая единица — 1 день. 7 ресурсов: золото (единая валюта),
  древесина, руда, кристаллы, сера, ртуть, эссенция (у шести по 2-3 применения).
- Лидерство: жёсткий лимит, перегруз невозможен. Армия с героем: ёмкость =
  hero.Leadership. Отряд без героя: ёмкость = 50. Найм/передача блокируются при превышении.
- Слоты армии: 5. Герой не занимает слот, в армии один главнокомандующий.
- Герой НЕ участвует в бою напрямую: нет токена на поле, нет HP на поле.
  Герой даёт пассивные бонусы, кастует заклинание 1/раунд через командную панель,
  командная способность 1/бой.
- Защита: +25% защиты до следующего хода, БЕЗ резистов, инициативу НЕ снижает.
- Контратака: автоматическая, 1/раунд, НЕ действие игрока.
- Резисты: физический, магический, ядовитый, огненный, огнестрельный.
- Мораль: экспоненциальная, описательная, диапазон −4…+4, оба эффекта
  (шанс доп. действия/пропуска + модификатор атаки/защиты), капы 35%/16%,
  нежить/конструкты иммунны. Формулы в GDD §7.5.
- Побег: герой бросает армию, шанс clamp(65+logistics×3−enemyLogistics×2,20,90)%.
  Успех → ближайшее своё поселение к началу следующего дня, без армии,
  минус 1–3 случайных артефакта противнику. Провал → плен 5 дней.
- Выкуп: Σ(unitPrice×count) + heroLevel×1000 + 100×artifactCount.
  Оплата → герой и армия сохраняются, ближайшее поселение, 0 MP.
- Захват поселения: все здания авто-удаляются, уровень сбрасывается до 1,
  шаблон переключается на фракцию захватчика, улучшать по правилам своей фракции.
- Ветеранство: бесплатно, ранги 1–5 описательно, по побеждённым отрядам
  (пороги 0/2/5/10/18), за ранг выше 1: +2 atk, +2 def, +1 п.п. crit chance,
  +1 п.п. crit damage. Названия: Новобранцы/Обстрелянные/Ветераны/Закалённые/Легенды.
- Карточка юнита: рамка и фон цветов фракции, тир, описательный ранг, тип
  передвижения, все поля GDD §8, боезапас НЕ показывать.
- Уникальные классы героев фракций механически, не только названия:
  Маршал Предела, Архивариус Пепла, Троповед Клани — GDD §9.3.
- Боезапас стрелков: в MVP нет, поле в data зарезервировано.
